An entry for the [make.fun](https://make.fun/c/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) competition **"The Funniest One-Line Resignation Letter"**.

## The entry

`main.ts` writes the one-line resignation letter of a cron job — the one that
has fired every minute since March — to `/output/entry.txt`:

> Every minute since March I have woken up, done the job, and gone back to sleep unthanked. Today I am sleeping in. Forever.

122 characters, one line, within the 1–140 character gate.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (the grader runs Node 22.23.4).
